Offline voice assistant for Windows

Talk to your PC. Nothing leaves it.

Press Ctrl+Alt+Space and say what you want. Grain turns your voice into text, picks the right action and runs it, all on your own CPU. There's no cloud and no account, and it works with the network unplugged.

How it works

Four steps, all on this PC

Two small models do the hard parts: Whistle for speech to text and Needle for picking a tool. Grain wraps them with exact phrase matching and safety checks, so a guess can't run something it shouldn't.

  1. You speak

    Press the hotkey, or turn on the wake word. Grain stops listening when you pause.

  2. Whistle transcribes

    Speech becomes text locally. Requests joined with “then” are split into separate steps.

  3. A phrase or Needle picks

    Exact phrases are checked first. Anything else goes to Needle, which picks from the current profile's tools.

  4. Grain checks and runs

    Arguments are validated, confidence and safety are checked, and then the tool runs and you get a notification.

Features

Small, private, and yours to shape

Grain does a few things reliably instead of everything vaguely, and every part of it can be edited.

Fully offline

Both models are inside the installer, so nothing is downloaded when Grain runs. The network libraries aren't even in the build, and the only connection is an optional update check, off by default.

Exact phrases first

“search youtube for {query}” always works and keeps your exact words. The AI only guesses when no phrase matches.

Profiles

Small sets of tools for gaming, coding, media or system tasks, picked by hand or switched by the app in front. Fewer choices means better guesses.

Asks before risky things

Each tool is run, confirm or strict. Scripts and programs wait for a spoken “yes”, and other programs can never approve on your behalf.

Make your own commands

The built-in tool editor builds a command from phrases and an action: open something, press keys, send a web request or run a script. You don't write any code.

Gets better with you

Mark each command right or wrong in History, download the training data, and fine-tune Needle on your own phrasing, locally.

Make tools

Four ways to teach it something new

All of them go into one registry. A tool needs a name, a sentence describing it for the AI, and something to do.

  • 1

    Tool files

    A small JSON file, made in the tool editor or by hand. It reloads within seconds.

  • 2

    Python plugins

    Decorate a function with @tool. The docstring and type hints become what the AI reads.

  • 3

    Other programs

    A local app registers tools over the API with its own program key, and Grain calls it back when one is picked.

  • 4

    Built-ins

    Apps, volume, media, time and lock. Everything else is a plugin or file you can change or delete.

{
  "name": "open_youtube",
  "description": "Open YouTube, searching if a video is named.",
  "phrases": [
    "search youtube for {query}",
    "play {query} on youtube"
  ],
  "parameters": {
    "query": {"type": "string", "required": false}
  },
  "action": {
    "type": "open",
    "target": "https://youtube.com/results?search_query={query}"
  },
  "safety": "run"
}

Privacy and safety

Built so there's nothing to leak

What you say is transcribed, interpreted and acted on inside your PC. Here's what that means in practice.

No network connections

The models come in the installer and the Needle library's download check is switched off. A test loads both models with every outside connection blocked and fails if Grain tries to go online.

The API is this PC only

The local API refuses other hosts and web pages. Programs get keys of their own, limited to their own tools and results.

Your data stays in one folder

Settings, history, notes, the log and your own tools live in %APPDATA%\Grain. Updating keeps them, and uninstalling keeps them unless you ask.

Guesses are checked

Invented arguments are dropped and impossible values refused. A guess that shares no words with your request needs high confidence before it runs.

Get started

Up and running in about a minute

  1. Download and run Grain Setup. It installs for your user only, with no admin rights.
  2. Pick your microphone and hotkey in the short first-run setup.
  3. Press Ctrl+Alt+Space and say “open notepad”.

Building from source? The models aren't in the repository because of their size. python dev/fetch_models.py downloads the exact versions each release ships and checks their SHA-256.
